## 🚀 Quick Deploy Tutorial (2026 Edition)

### Step 1: Choose Hosting Panel
- [Spaceify](https://client.spaceify.eu) ← Recommended  
- [bot-hosting.net](https://bot-hosting.net)

### Step 2: Create Server on Spaceify
1. Go to [client.spaceify.eu](https://client.spaceify.eu)
2. Register → Login
3. Create Server → Node.js → Germany → Max Storage

### Step 3: Upload & Launch
1. Upload XADON AI `.zip`
2. Unarchive → Move all files to root (`../`)
3. Console → Start

### Step 4: Connect WhatsApp
- Scan QR or use Pairing Code  
- WhatsApp → Linked Devices → Link

> **Pro Tip**: Run `npm install` if modules are missing.
